🤖 توليد AI الحقيقي

أنشئ API خلفيًا على خدمة موثوقة (مثل Supabase Edge Functions) ليتصل بمزوّد الذكاء الاصطناعي. لا تضع مفتاح API في هذا الملف.

يُحفظ العنوان محليًا فقط. لا تلصق أي مفتاح سري هنا.

🗃️ مجتمع مشترك

لظهور المنشورات والتعليقات والإعجابات على كل الأجهزة، اربط قاعدة بيانات مثل Supabase وأنشئ سياسات وصول آمنة.

استخدم المفتاح العام فقط مع سياسات قاعدة بيانات صحيحة. ممنوع وضع service_role key في المتصفح.

مهم: حفظ رابط Supabase في الواجهة وحده لا ينشئ الجداول أو يضمن أمانها. يجب إعداد الجداول وسياسات RLS أولًا. في النسخة الحالية، الأفكار محلية حتى يتم استكمال ربط Supabase.

خطة الإطلاق المجانية

  1. ارفع index.html إلى GitHub.
  2. فعّل GitHub Pages لنشر الواجهة.
  3. أنشئ مشروع Supabase للجداول والمجتمع.
  4. أنشئ وظيفة خلفية آمنة لتوليد AI، ثم ضع عنوانها في الحقل أعلاه.
  5. اختبر كل ميزة من جهاز آخر قبل إعلان أن المجتمع يعمل.
